# Build notes

A template. Copy it to `BUILD_NOTES.md`, which git ignores, and keep it up as you build. It records
what's true on your machine and what you've learned, so your next session or agent doesn't pay to
find out again. Keep it short: an agent reads all of it, every garment. Delete what's gone stale.
Facts about a book go in the tracked SOURCE_NOTES.md instead, where everyone benefits.
