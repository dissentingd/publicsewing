The patterns draft from body measurements, not garment sizes: the ease is in the design. Measure
over light underwear, standing relaxed, with a helper if you can.

- Use a soft tape. Keep it level and snug, not tight.
- Tie a string round your natural waist first and leave it there: several lengths start from it.

Pick a garment to see only what it needs. As you enter each measurement it's kept in this browser
and never sent anywhere, and every design offers them as **My measurements**.

## Measuring a child

The same measurements work. Measure over light underwear, with the child standing as straight and
relaxed as they can, and measure again if a number looks odd. Children grow quickly, so measure
fresh for each new garment.

## Not ready to measure?

Pick a size set in the pattern tool instead: FreeSewing's adult sets, three stout figures, or the
75 children's sets from the USDA's 1939 survey of American children (B, C and D are a slimmer,
average and fuller hip at each height).
