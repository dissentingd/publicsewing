Sewed a muslin? Please tell us how it went, whether it fit or not.

**[Open a muslin report on GitHub](https://github.com/dissentingd/publicsewing/issues/new?template=muslin-report.yml)**
(needs a free GitHub account).

The form asks for the design, the size set or measurements you used, the fabric, what fit and
what didn't, any options you changed, and photos. Everything in a GitHub issue is public: leave
your measurements out if you'd rather not share them, and crop faces from photos.

Each report is recorded in the design's brief. A design moves from *draft* to *tested* once a
muslin has been reported.
